A  Power BI dashboard designed to monitor financial activity, evaluate operational risks, and analyse 
customer demographics. It consolidates transaction volumes, fees, and operational health into a single 
interactive view to drive data-backed strategic decisions.

It is based on two data sets: transactions and customers. The former is responsible for information related
to money, fees, etc, while the latter has information about clients such as geography, names and segment.

We have dynamic metrics in the project to adapt the visualisations for the different needs, several types of
data visualisations, necessary filters, and detailed information about transactions on the second page.

Customer data was created synthetically using Python + Faker. Transactions data was extracted from the
open sources, but it had some issues. Thus, it was corrected during data preparation. During data modeling,
new tables and columns were created to organize vizualizations preperly.
